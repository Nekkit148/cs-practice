Рабочая папка это обычная папка где пользователь работает с файлами проекта
Индекс - промежуточная область между файлами на диске и репозиторием
Коммит - Снимок состояния всего проекта в определенный момент времени

git - программа на компьютере
GitHub - онлайн-платформа для репозиториев

Использованные команды
git status показывает текущее состояние репозитория
git diff показывает различия между разными состояниями файлов и коммитов
git diff --staged показывает различия между индексом и последним коммитом

Ветки:
Ветка - это указатель на определённый коммит в истории проекта
Git создаёт новый коммит с определёнными изменениями при выполнении коммита
Слияние веток в Git — это процесс интеграции изменений из одной ветки в другую
