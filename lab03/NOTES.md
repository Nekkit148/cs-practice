git log выводит список коммитов в обратном хронологическом порядке.
git show показывает подробную информацию об объекте Git.
git diff инициирует сравнение и показывает различия между двумя наборами данных.

log -S и blame выводят информацию о строках файла.

git restore копирует чистую версию файла в указанное место.

git restore --source=... Ключевое отличие в том, что --source позволяет явно указать источник версии файла.
